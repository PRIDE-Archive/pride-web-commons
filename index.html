Web Component · Custom Elements v1

PRIDE Web Commons Demo & Documentation

A lightweight, framework-agnostic shared shell containing the EMBL-EBI Global Bar, PRIDE Announcement Alert Banner, PRIDE Main Navigation, and ELIXIR / EMBL-EBI Global Footer.

Zero dependencies. Encapsulated in Shadow DOM so styles never clash with host applications. Drop into plain HTML, Vue, Angular, React, MkDocs, or backend templates.

Integration Guide

Include via CDN in any webpage:

<!-- Load via jsDelivr CDN (or GitHub Pages) -->
<script type="module" src="https://cdn.jsdelivr.net/gh/PRIDE-Archive/pride-web-commons@main/dist/pride-web-commons.js"></script>

<!-- Top Navigation -->
<pride-header active-section="tools"></pride-header>

<!-- Your Application Content -->
<main id="content">
  ...
</main>

<!-- Footer -->
<pride-footer></pride-footer>
